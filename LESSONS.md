# Lessons for KOML

The domain needs explicit units and a stated policy before a score can mean
anything. Multiplying estimates is easy; preserving the distinction between
estimated value and measured benefit is the important operating boundary.

Synthetic evidence validates deterministic arithmetic, planted threshold
classification, exact reconciliation and input-driven computation. It does
not validate that reversibility deserves this weight or that the ranking earns
daily use. Those assumptions remain open for the two-week real-use trial.

Adversarial tests exposed a CSV error-line bug and accidental re-ingestion of
a saved results file. Both were fixed before acceptance. The operating rule
for future builds: keep an independent oracle, mutate the actual inputs, and
verify output changes before claiming computational accuracy.
